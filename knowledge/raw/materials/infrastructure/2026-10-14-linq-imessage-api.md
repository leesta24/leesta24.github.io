## 一句话摘要

通过 REST API 与事件回调，把 Agent 放进既有消息渠道。

## 主要要点

- 支持 iMessage、RCS/SMS fallback、群聊、富媒体、回执与正在输入等交互。
- Webhooks 将会话事件送回应用，适合消息驱动的助理入口。
- 它提供第三方接入基础设施；不能称作 Apple 官方公开 API。
