一句话摘要

以人类行为分布为目标，研究比通用助手更真实的用户模拟。

主要要点

  • 输入情境与用户画像，模拟个体及多人对话中的行为变化。
  • Multi-User Turing Test 让裁判区分真实与模拟续写；50% 混淆率代表该测试中的不可区分基线。
  • 适合为 Personal Agent 和群聊交互构建更有差异的测试用户，而不只用配合度很高的通用 LLM。

证据与局限

研究预览与发布方评测；本次阅读介绍和评测方法，没有调用 API，也没有验证对实际 Agent 评测的增益。
