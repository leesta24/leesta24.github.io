一句话摘要

围绕用户授权与商家控制，统一个人 Agent 访问网站、API 和企业 Agent 的会话。

主要要点

  • 从网站发现服务，先以访客身份启动；需要账户能力时再登录授权。
  • 基于 OAuth，用户选择读写权限；网站、MCP/OpenAPI 接口及企业 Agent 可共享连续会话。
  • 适合研究个人 Agent 如何代表用户行动，而不只解决工具调用格式。
